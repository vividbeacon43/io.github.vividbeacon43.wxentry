# WXEntry · 微信增强模块（内核版）

> 📢 **更新与反馈请关注 Telegram 频道：https://t.me/Wxentry**

一个面向 **微信 8.0.80** 的 Xposed 模块：安装后只是一个「引导器」，激活成功后从服务器下发加密内核，
功能全部跑在内存里，不在本地留明文代码。

**支持版本：微信 8.0.80（3220）—— 其它版本装上也不会有任何功能。**
（内核启动会自检版本，不是 8.0.80 直接停用，不会弹错误、不会干扰微信。）

## 功能

### 聊天

| 功能 | 说明 | 默认 |
|---|---|---|
| 防撤回 | 对方撤回的消息本地保留原文，并补一条「××× 撤回了一条消息」的提示；撤回的图片也能正常点开看原图 | 关 |
| 撤回图片备份 | 撤回时把图片留底，可在菜单里直接预览（不写相册、不需要存储权限） | 关 |
| 一键已读 | 所有会话未读清零 | — |
| 清空聊天列表 | 按「公众号 / 群聊 / 个人」分类批量清理会话，可选连消息一起删 | — |
| 新群免打扰 | 新加入的群聊自动设为消息免打扰 | 关 |

### 朋友圈

| 功能 | 说明 | 默认 |
|---|---|---|
| **朋友圈防删** | 朋友删掉的动态，在你这儿继续保留，正文前自动标注「（这条朋友圈被删除啦）」，图片 / 评论 / 点赞都还在 | 关 |

> 原理：微信在作者删帖时并不删除本地数据，只是把这条动态的「时间线显示位」清掉。
> 模块拦住这个清位动作，所以数据不需要额外备份，显示效果是原生的。
> 自己删自己的朋友圈、广告类动态不受影响。

### 其它

|---|---|---|

| 原图 | 发图时默认勾选「原图」 | 关 |
| 抢红包 | 自动领取红包，支持按群白名单、延迟、模式设置 | 关 |
| 公众号取关 | 批量取消关注公众号，并清理对应会话 | — |
| 检查内核更新 | 有新内核时菜单里会变成「新版本 vXX，点此更新」 | — |
| 重启微信 | 一键重启微信进程（改动后彻底生效用） | — |

## 安装

1. **环境**：已 Root + **LSPosed**（Zygisk 版）；
2. 安装 APK；
3. 打开 LSPosed → 模块 → 勾选 **WXEntry**
   （APK 已声明推荐作用域，**会自动推荐「微信」**，确认勾上即可）；
4. 强制停止微信后重新打开。

## 激活

首次打开微信会弹出激活框，显示你的微信号（wxid）。

把**激活码**粘进去 → 点「激活」→ 自动下载内核 → 提示「激活成功，功能已开启」。
**不需要手动重启微信**：内核会立刻加载并重建界面。

> 激活码与微信号绑定（不绑设备），换手机登录同一微信号仍然可用；
> 换微信号需要用新的激活码。激活后本地保存凭证，之后启动不再联网校验。

## 使用

长按微信首页右上角 **＋** 弹出功能菜单，点一下即可开 / 关对应功能。

首次安装**所有功能默认关闭**，按需开启。

## 常见问题

**Q：装上去没有任何功能？**
A：① 确认微信是 8.0.80（其它版本内核会直接停用）；② 确认 LSPosed 里勾选了模块并给了微信作用域；③ 确认已激活。

**Q：朋友圈防删没生效？**
A：菜单里「朋友圈防删」要处于「开」；另外只有**别人**的动态会保留，自己删自己的正常删除。

**Q：内核怎么更新？**
A：微信启动 8 秒后会后台比对版本；有新版时首页会出现横幅，或菜单里点「检查内核更新」。更新后重启微信生效。

**Q：会不会收集聊天内容？**
A：不会。除激活/内核下载与真名功能按需查询外，模块不向服务器上传任何聊天或朋友圈内容。

## 已知限制

1. 仅支持微信 8.0.80（3220）；
2. 广告类动态不保留；
3. 自己删自己的朋友圈不拦截；
4. 微信大版本升级后需要等待内核适配。

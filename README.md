# WXEntry · 微信增强模块（内核版）

> 📢 **快来频道一起聊天：https://t.me/Wxentry**

面向 **微信 8.0.80** 的 Xposed 模块：安装后只是一个「引导器」，激活成功后从服务器下发加密内核，功能全部跑在内存里，不在本地留明文代码。

**支持版本：微信 8.0.80（versionCode 3220）** —— 其它版本内核自检后直接停用并弹提示，不会干扰微信。

装好后长按微信首页右上角 **＋** →「微信增强」，所有功能都在里面开关，**默认全关，按需打开**。

## 功能

### 💬 聊天

- **防撤回** —— 对方撤回的消息留在本地，原消息后标注「（已撤回）」；撤回的图片、视频、文件、语音都能正常打开
- **语音防撤回 + 批量转发语音** —— 一条语音可转发到多个会话，自动排队发送
- **自动下载原图** —— 收到图片自动下原图，独立开关，与防撤回互不影响
- **原图下载名单** —— 个人 / 群聊分开设白名单或黑名单，支持搜索
- **撤回图片备份** —— 撤回的图片留底，可在菜单里直接预览（不写相册、不需要存储权限）
- **一键已读** —— 所有会话未读清零，不会把公众号拉出分组
- **清空聊天列表** —— 按公众号 / 群聊 / 个人分类批量清理，可选连消息一起删
- **新群自动免打扰** · **公众号批量取关**
- **真名** —— 群里直接显示成员真实备注名，按需查询、低功耗调度，关掉即恢复

### 🧧 红包 / 转账

- **抢红包** —— 免费版自动打开微信原生领取页并拆包（新旧页面都跟随微信）；高级版 / VIP 可选静默模式
- **名单 + 延时** —— 个人 / 群聊分别配置黑白名单，按秒数延时，不重复领
- **自动接收转账**（高级版 / VIP）—— 到账以微信原生查询为准，不把提交成功当成到账
- **关键词过滤**（VIP）—— 红包按祝福语、转账按备注设关键词：命中就跳过，或只处理命中的；支持模糊（包含）/ 精确（全等），与名单、延时同时生效

### 🌈 朋友圈

- **朋友圈防删** —— 别人删掉的动态在你这儿继续保留，标注「（这条朋友圈被删除啦）」，图片 / 评论 / 点赞都还在
- **一键转发**（高级版 / VIP）—— 文字、图文、九宫格、短视频、链接、视频号卡片，准备好素材和文案直接带到发表页，发不发你自己点
- **朋友圈去广告**（高级版 / VIP）—— 按原生标记过滤时间线广告，关掉刷新即恢复
- **伪集赞**（高级版 / VIP）—— 微信原生点赞样式（爱心 + 好友姓名，点姓名进资料页）；支持搜索、全选、按人数随机抽选，不限制人数
- **伪评论**（高级版 / VIP）—— 选好友逐人写内容或用预设，可长按编辑、删除，长列表可展开
- **定时发朋友圈**（VIP）—— 文字 / 纯图片 / 图文任务，最多 9 张图，设定日期时间与可见范围（公开 / 仅自己可见）；到点通过微信原生图文通道发布，错过时间会先提醒你确认再补发

> 伪集赞 / 伪评论只在本机显示，不点赞、不评论、不通知对方，也不写微信数据库。

## 安装

1. **环境**：已 Root + **LSPosed**（Zygisk 版）；
2. 安装 APK；
3. 打开 LSPosed → 模块 → 勾选 **WXEntry**（APK 已声明推荐作用域，会自动推荐「微信」，确认勾上即可）；
4. 强制停止微信后重新打开。

## 激活

> **激活码在频道置顶消息里领取 · 快来频道一起聊天：https://t.me/Wxentry**

首次打开微信会弹出激活框，显示你的微信号（wxid）。把激活码粘进去 → 点「激活」→ 自动下载内核 → 提示「激活成功」。

激活码与微信号绑定（不绑设备）：换手机登录同一微信号仍然可用，换微信号需要新的激活码。

## 使用

1. 长按微信首页右上角 **＋** →「微信增强」；
2. 菜单分「聊天 / 红包 / 防撤回 / 朋友圈 / 设置与支持」，进去后在对应类别里开关功能；
3. 需要多层设置的（名单、关键词、评论预设）在对应子页里配置；
4. 有新内核时菜单里会出现更新提示，更新后重启微信生效。

**关键词过滤（VIP）**：菜单 → 红包 →「红包关键词过滤」/「转账关键词过滤」。每行一个词（最多 100 个、每个 200 字），两个滑块互斥：选「命中就跳过」则碰到词就不处理，选「只领取命中的」则只处理包含关键词的。只读红包祝福语 / 转账备注，规则改动从下一条消息开始生效。

**平板模式（高级版 / VIP）**：菜单 → 设置 → 实验功能 → 平板模式 → 重启微信；登录页也能打开实验功能，用「平板扫码登录」。

**定时发朋友圈（VIP）**：菜单 → 朋友圈 → 定时发朋友圈。选文字 / 图片 / 图文（最多 9 张），设日期时间与「公开 / 仅自己可见」，点「保存并开启定时发布」即排程；任务列表里可查看、编辑、取消。到点需要微信在运行、已登录、有网络，模块用精确闹钟唤醒（不点亮屏幕）；如果错过了时间，任务会变成「待确认」，你在详情里点确认才会补发，不会自动重发。

## 常见问题

**Q：装上去没有任何功能？**
A：① 确认微信是 8.0.80；② 确认 LSPosed 里勾选了模块并给了微信作用域；③ 确认已激活，模块版本与内核均为最新。

**Q：朋友圈防删没生效？**
A：菜单里「朋友圈防删」要处于「开」；只有**别人**的动态会保留，自己删自己的正常删除。

**Q：开启防撤回后，撤回的视频 / 文件能看吗？**
A：能。视频、短视频和附件会在撤回前留一份模块私有副本（默认 3 分钟内有效，单文件 256 MiB、总量 512 MiB 上限），超过期限未撤回的副本会自动清掉。

**Q：免费版红包没自动领到？**
A：① 自动领取依赖微信在前台；② 过期、领完、需要实名 / 验证的红包不会强行操作；③ 更新后请用**新收到**的红包复测，不会补领历史红包。

**Q：伪集赞 / 伪评论会被对方看到吗？**
A：不会。没有真实点赞、评论请求，好友不会收到通知，也不出现在对方朋友圈。

**Q：定时发朋友圈为什么没准点发出去？**
A：定时依赖微信进程在运行且网络可用；被系统冻结、清理后台或断网时无法保证准点，此时任务会转为「待确认」，你打开模块确认后才会补发。另外需要在系统里给微信「闹钟和提醒」权限，否则到点不会被唤醒。

**Q：内核怎么更新？**
A：微信启动 8 秒后后台比对版本；有新版时首页会出现横幅，或菜单里点「检查内核更新」。更新后重启微信生效。

**Q：会不会收集聊天内容？**
A：不会。除激活 / 内核下载与真名功能按需查询外，模块不向服务器上传任何聊天或朋友圈内容。

## 源码

本仓库 `source/` 目录是最新发布版本的完整源码（与线上 APK / 内核一一对应）；历史版本可在提交记录中查看：

- `source/loader/`：模块 APK 侧的引导器（激活、内核下载与校验）
- `source/kernel/`：内核功能代码（免费 / 高级 / VIP 三个通道）
- `source/build/`、`source/tests/`：构建脚本与校验用例
- `source/SHA256SUMS`、`source/validation.json`：构建产物与依赖校验值

源码包不含签名私钥、密码、激活记录与用户自检日志。

**构建**：Python 3 + JDK 17，依赖 `android.jar`、`xposed-api-82.jar`、`d8.jar`；
依次运行 `build/build_kernels.py` → `build/build_loader.py` → `build/repack_apk.py`（最后一步需要原 APK 基线与证书材料，路径见脚本内配置）。

## 已知限制

1. 仅支持微信 8.0.80（3220）；平板模式需先激活并把内核更新到当前版本（高级版 / VIP）；
2. 广告类朋友圈动态不保留；
3. 自己删自己的朋友圈不拦截；
4. 微信大版本升级后需要等待内核适配。

# WXEntry · 微信增强模块（内核版）

> 📢 **快来频道一起聊天：https://t.me/Wxentry**

一个面向 **微信 8.0.80** 的 Xposed 模块：安装后只是一个「引导器」，激活成功后从服务器下发加密内核，
功能全部跑在内存里，不在本地留明文代码。

**支持版本：微信 8.0.80（versionCode 3220）—— 其它版本内核自检后直接停用，不会有任何功能。**
（内核启动会自检版本号，不符合就直接停用，并弹一条提示说明原因，不会干扰微信。）

## 源码

本仓库 `source/` 目录是最新发布版本的完整源码（与线上 APK / 内核一一对应）；历史版本可在提交记录中查看：

- `source/loader/`：模块 APK 侧的引导器（激活、内核下载与校验）
- `source/kernel/`：内核功能代码（免费 / 高级 / VIP 三个通道）
- `source/build/`、`source/tests/`：构建脚本与校验用例
- `source/SHA256SUMS`、`source/validation.json`：构建产物与依赖校验值

源码包不含签名私钥、密码、激活记录与用户自检日志。

**构建**：Python 3 + JDK 17，依赖 `android.jar`、`xposed-api-82.jar`、`d8.jar`；
依次运行 `build/build_kernels.py` → `build/build_loader.py` → `build/repack_apk.py`（最后一步需要原 APK 基线与证书材料，路径见脚本内配置）。

## 安装

1. **环境**：已 Root + **LSPosed**（Zygisk 版）；
2. 安装 APK；
3. 打开 LSPosed → 模块 → 勾选 **WXEntry**
   （APK 已声明推荐作用域，**会自动推荐「微信」**，确认勾上即可）；
4. 强制停止微信后重新打开。

## 使用

长按微信首页右上角 **＋** 弹出功能菜单，点一下即可开 / 关对应功能。

首次安装**所有功能默认关闭**，按需开启。

**自动下载原图 / 下载名单**：菜单 → 聊天 → 自动下载原图；同一处可进入「原图下载黑白名单」，个人与群聊分开设置。白名单与黑名单互斥，两个都不启用时不限名单，启用空白名单则不处理任何人。

**名单规则（红包 / 转账 / 原图下载通用）**：三类名单分开保存、按微信号隔离，个人与群聊分别设置。总开关关闭不处理；分类关闭不处理该类别；分类开启时——白名单为空 = 处理全部，白名单有选项 = 只处理选中的，启用黑名单 = 只跳过选中的。

**朋友圈两个开关（高级版 / VIP）**：菜单 → 朋友圈，里面是「朋友圈一键转发」和「朋友圈去广告」两个独立滑块，按微信号分别保存。
- 一键转发：默认开启。长按别人的朋友圈 → 一键转发 → 进入原生发表页，编辑后自己点发表；模块不会自动发布，素材不可用或超时会直接不打开草稿。
- 去广告：默认关闭。开启后刷新朋友圈生效，关闭再刷新就恢复原样；只影响时间线展示，不改动微信数据。

**朋友圈本地互动（高级版 / VIP）**：菜单 → 朋友圈，开启「伪集赞」「伪评论」后长按目标朋友圈文案即可使用。支持搜索多选好友、评论预设、长按编辑/删除；菜单里可「清空本地互动记录」。这些内容只存在本机的模块目录里，不写微信数据库、不产生真实互动，关闭开关后显示消失但记录保留，再打开可恢复。

**平板模式（高级版 / VIP）**：菜单 → 设置 → 实验功能 → 平板模式 → 重启微信；登录页同样可以进入实验功能，用「平板扫码登录」由微信原生生成二维码，扫码与确认都在你自己手上完成。免费版与未激活用户看不到该分类。

## 常见问题

**Q：装上去没有任何功能？**
A：① 确认微信是 8.0.80（其它版本内核会直接停用并弹提示）；② 确认 LSPosed 里勾选了模块并给了微信作用域；③ 确认已激活，模块版本与内核均为最新。

**Q：朋友圈防删没生效？**
A：菜单里「朋友圈防删」要处于「开」；另外只有**别人**的动态会保留，自己删自己的正常删除。

**Q：开启防撤回后，撤回的视频 / 文件能看吗？**
A：能。收到的视频、短视频和附件会在撤回前留一份模块私有副本（默认 3 分钟内有效，单文件 256 MiB、总量 512 MiB 上限），撤回后仍可正常打开；超过期限未撤回的副本会自动清掉，不影响微信自己的文件。

**Q：朋友圈「一键转发」会自动帮我发出去吗？**
A：不会。它只准备素材和文案并打开你的发表页，发不发自你决定；图片最多 20 张、单个文件 256 MiB、缓存总量 512 MiB，准备任务最长 3 分钟。

**Q：免费版红包没自动领到？**
A：① 自动领取依赖微信在前台，锁屏或微信在后台时可能不触发；② 红包已过期、已被领完、需要实名 / 验证的红包不会强行操作；③ 更新内核后请用**新收到**的红包复测，模块不会去补领历史红包。

**Q：伪集赞 / 伪评论会被对方看到吗？**
A：不会。它只在你自己的微信界面上多显示一层内容，没有真实点赞、评论请求，好友不会收到任何通知，也不会出现在对方的朋友圈里。

**Q：内核怎么更新？**
A：微信启动 8 秒后会后台比对版本；有新版时首页会出现横幅，或菜单里点「检查内核更新」。更新后重启微信生效。

**Q：会不会收集聊天内容？**
A：不会。除激活/内核下载与真名功能按需查询外，模块不向服务器上传任何聊天或朋友圈内容。

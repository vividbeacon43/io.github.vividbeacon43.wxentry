# WXEntry 2.17 / 动态内核 v258

本次新增 VIP「定时发朋友圈」，入口：模块菜单 → 朋友圈 → 定时发朋友圈（VIP）。其他功能沿用 v256。

## 定时图文

- 可创建文字、纯图片或图文任务，最多 9 张图片，设置日期、时间及公开 / 仅自己可见。
- 保存按钮明确为「保存并开启定时发布」。提供右侧蓝 / 灰开关，支持查看、编辑、取消和删除已结束任务记录。
- 任务绑定创建时的微信账号，提交前核验当前账号、有效 VIP 签名授权、文字、图片数量、文件摘要和可见范围。免费 / 高级内核不包含定时发布实现。
- 使用当前微信原生图文上传通道；提交前持久化任务状态，取得本地记录后继续核对微信服务器结果。结果不明不会自动重新提交。
- 微信停止运行、被系统挂起后错过时间、准备超时或系统时间大幅变动时，任务进入待确认状态。恢复后提醒，用户在详情中确认才补发。
- 息屏时使用私有精确闹钟在计划前约 2 秒尝试唤醒，申请最长 90 秒的部分 CPU 唤醒锁，完成后尽快释放，不点亮屏幕或解锁。系统缺少微信的「闹钟和提醒」权限时提供设置入口。
- 需保持微信进程运行、账号已登录及网络可用。系统冻结 / 杀进程时不能保证准点；本模块不启动额外保活服务。
- 本次原生发布适配并实测微信 8.0.80（3220）；其他微信版本在未适配时显示原因，不尝试调用未验证发布接口。
- 每账号最多 20 个待处理任务、60 条任务记录；单图最多 32 MiB，模块定时图片缓存总量最多 512 MiB。复制系统选择器返回的图片，保留返回顺序；完成 / 取消后清理模块副本，不删除原图或微信缓存。上传结果未知时保留可能仍需使用的模块副本。
- 计划时间保存为绝对时间，页面显示手机当前本地时间和时区。

原有「一键转发朋友圈」继续只打开编辑页，由用户点击发表。它与本次用户主动保存的定时发布任务分别实现。

## 源码与构建

- kernel：三版内核及功能实现；SnsSchedule*.java 仅编入 VIP。
- loader：模块加载器、签名内核分发及 DEX 兼容处理。
- tests：行为、账号 / 权限、持久化失败、原生 DEX 接口及加载器检查。
- build：构建、APK 重打包及更新清单校验脚本。
- server：与现网一致的服务端源码，本次未修改服务端程序。
- baseline-v212 / licenses：回归基线和依赖许可证。

构建需要 JDK 17、Android android.jar、Xposed API 82、D8、dexlib2 / jadx-all.jar。工具链和微信 APK 不随源码分发。build/build_kernels.py 支持 --java-bin、--libs、--python-libs、--native-apk。--signing-key 可选；未提供时只构建和检查，不生成可发布签名。build/build_loader.py 和 build/repack_apk.py 的本机工具链路径须按自己的环境配置。

APK 必须继续使用自己的原证书；本源码包不含签名私钥、证书库密码、服务器密码、用户激活数据、设备日志、测试图片或反编译的微信源码。请参阅 TESTING.md 与 RELEASE.json 中的验证范围和文件摘要。

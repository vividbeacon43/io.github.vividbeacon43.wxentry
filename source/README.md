# WXEntry 2.11 / 动态内核 v252

对应免费、高级、VIP三通道v252和模块APK2.11。新增的朋友圈伪集赞、伪评论仅向已验证的高级版和VIP开放，作为本机展示功能，不会产生真实点赞、评论或好友通知。

## 使用

进入模块菜单 → 朋友圈，分别开启“朋友圈伪集赞”和“朋友圈伪评论”，默认均关闭。开关沿用右侧小滑块，开为蓝色，关为灰色。长按目标朋友圈文案，选择伪集赞或伪评论；原有一键转发入口继续保留。

伪集赞支持搜索并多选真实好友，按最近聊天排序；已选好友再次打开时回显，可取消选择。头像由微信原生头像加载器提供，点击头像或姓名打开该好友的原生资料页。每条最多100位。

伪评论先选择好友，再逐人填写内容或选择预设。“伪评论内容预设”中每行一条，最多50条；每条评论1～500字。一次最多添加20位好友，每条朋友圈最多保存100条。长按已有本地评论可以编辑或删除，点击头像、姓名打开资料页；长按不会再误触资料链接。长列表可展开查看。

关闭对应开关后，移除该类本地展示，记录仍保留，再开启可恢复。长按文案中的“清除本条本地互动”只清理当前朋友圈；菜单“清空本地互动记录”清理当前账号的全部记录，保留开关和预设。

## 数据与显示

记录保存在模块私有目录的独立账号文件中，使用账号、作者和朋友圈ID定位，不复用真实评论ID，不写微信朋友圈数据库或原生互动协议对象。原有朋友圈设置格式不变。仅追加可单独移除的本地视图；真实评论的文字、表情和图片保留，已真实点赞的同一好友不重复显示。

每个账号最多保留200条朋友圈记录，文件上限2MiB；达到上限时淘汰最久未编辑的记录，优先保留当前操作的目标。文件损坏时禁止静默覆盖，用户可通过明确的清空操作恢复。切换账号、授权失效、关闭模块、免费内核或未激活状态不允许添加或展示付费本地互动。

## 验证

测试机为微信8.0.80（3220）和现有高级版账号。实测开关、长按菜单、好友多选、头像/姓名资料导航、评论预设、批量评论、编辑/单条删除、真实图片评论共存、单条/全部清理、滚动复用和重启保留；具体范围及最终字节见validation.json。临时本地互动与预设在测试后清理。没有为本次测试发送真实点赞、评论、朋友圈或联系人消息。

行为、原生接口与版本边界检查，以及168项加载器DEX兼容、81项最终DEX枚举反射、6项真实签名升级/前向回退、8项APK清单协议检查通过，明细见TESTING.md。旧APK2.05、2.07、2.09对本版三个内核的兼容结果见validation.json。静态检查和桩测试不代表所有微信版本或所有原生互动组合均经过手机实测。

## 保留与构建

保留v250原生可见红包入口、新旧红包页面支持及完整皮肤模型；免费版规则、转账、原图下载、名单和延时、媒体防撤回、朋友圈转发/去广告和平板权限不变。没有把本次朋友圈实测当作真实红包或转账到账验收。

构建需Python3、JDK17、Android/Xposed编译库、D8、jadx-all.jar、微信基线APK及自有签名材料，路径参数按本机调整。顺序为build/build_kernels.py、build/build_loader.py、build/repack_apk.py。打包脚本中的历史APK与回退输入也需配置。源码含三版内核、加载器、后台基线、测试及许可证，不含密钥、密码、真实激活、用户日志、手机数据库或截图。

发布前精确备份APK2.09/v250；预备APK2.12（2.09加载器逻辑）和清单v253（v250内核内容）用于可升级回退。回退不修改授权和聊天数据，本地互动文件保留但旧版不读取。v253/APK2.12已预留，后续正式版本从v254/APK2.13起。授权后台不修改、不重启服务。

# WXEntry 1.97 / 内核 v238：高级版与 VIP 专属平板模式

状态：APK 1.97 和免费/高级/VIP 三通道内核 v238 已发布。本次将平板模式和原生平板扫码登录限制为高级版与 VIP。连接手机已覆盖安装最终原证书签名包。

## 权限规则

只有有效激活、且当前激活绑定的已签名内核为 plus（高级版）或 vip（VIP）时，才可使用平板模式。免费版、未激活、缺少授权缓存、签名错误、缓存字节被修改、授权属于其他激活，均不放行。不信任本地版本名称或旧开关文件。

免费内核隐藏“实验功能”分类，直接调用开关及二维码入口也会检查权限。登录前加载器在安装平板识别钩子前验证激活签名、内核签名、激活绑定签名与内核哈希。免费/未激活用户即使旧版保存了开启状态，也不安装平板钩子。运行中收到降级或授权拒绝结果后撤销模块对平板判断的覆盖。

高级版/VIP 已有有效签名缓存时，可在尚未读取当前 wxid 的登录页使用。全新安装没有对应授权的用户需要先激活并下载高级版/VIP 内核，再开启平板模式并重启。实验功能默认关闭，设置按 Android 应用用户隔离。

## 安装与使用

需要覆盖安装 APK 1.97、更新对应内核至 v238 并重启微信。登录前权限检查属于 APK 加载器代码，只更新内核无法替换旧 APK 中的登录前逻辑；旧版本设备必须完成 APK 更新。

高级版/VIP：模块设置 → 实验功能 → 平板模式 → 重启微信。登录页也可打开实验功能，进入“平板扫码登录”。二维码由微信原生 LoginAsExDeviceUI / getloginqrcode 生成，扫码和确认由用户完成。

当前适配微信 8.0.80（3220）。原 APK SHA-256：9d9b6c516e8e07e437c81485fde21fe13ce4f61b37d19e793fff40c71be39c0e。加载器在应用 attach 阶段、账号识别之前检查授权和设置，并挂接原生平板环境判断。微信版本或二维码接口不匹配时不启用。

保留 1.95 的显式启动入口和定时重启修复、原子开关保存、欢迎页入口布局、未登录账号识别重试及二维码回调脱敏日志。二维码标识、密钥和原始响应不写日志。

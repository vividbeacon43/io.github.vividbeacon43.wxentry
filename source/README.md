# WXEntry 2.03 / 动态内核 v244

对应免费／高级／VIP 三通道发布源码。升级 APK 和内核后重启微信。验证记录及具体计数见 TESTING.md、validation.json；备份与回退命令见发布说明。

## 免费版红包与皮肤红包

免费版按最新要求改为前台自动领取：收到符合当前账号开关、个人／群聊分类和名单的红包后，按秒数延时自动拉起微信领取页面，并点击可见可用的拆包按钮。支持 LuckyMoneyNotHookReceiveUI 和 LuckyMoneyNewReceiveUI。手动打开的接收页也能自动拆包。自动拉起的任务不重复套用两次延时。

免费版不使用静默领取接口，也不自动回复。高级／VIP 可二选一前台与静默模式；普通皮肤红包使用新版页面的同一原生 n6／h6 查询拆包流程，静默模式不弹页面。微信要求实名、验证、特殊处理或红包已处理时不强行操作。直播、企业联合等特殊业务不等同于普通皮肤红包。

## 自动接收转账修复

实际收到的原生转账卡片可以没有 total_fee 和 fee_type 字段。旧版本把它们视为必填，提前跳过任务。本版允许缺失卡片金额，通过本次交易绑定的微信原生查询取得金额和币种，并核对收付款账号、接收状态和可用零钱渠道。确认请求使用核验后的原生金额；后续独立到账查询必须保持同一金额，才记录成功。

仍须高级／VIP 授权，自动转账开关按微信账号独立保存，切换账号不会继承另一账号的开关。名单、延时、重复消息、超时、账号变化及原生手动指引检查继续生效。不自动回扫收取历史消息，不以确认提交成功直接视为到账。新增阶段日志只记录类型、状态与校验结果，不记录交易号、正文或真实金额。

## 朋友圈一键转发

高级／VIP 在每条朋友圈长按菜单选择“一键转发”。支持文字、普通图文、类型 54 的新版图文和九宫格、普通短视频、网页链接、原生视频号分享卡片及有对应原生数据的公众号视频卡片。测试机的新版类型 54 图文曾被旧版类型 1 判断遗漏，现已兼容。

图文和普通短视频先通过微信原生下载服务准备完整素材，核验路径及文件后建立临时副本，保留文案和素材顺序。视频号保留原生分享卡片元数据并预加载封面，仍是视频号卡片，不擅自改成仅文字或剥离来源的本地视频。普通网页和音乐网页保留对应链接与封面。素材不可用、卡片无效或超时不打开残缺草稿。

最后仅进入微信原生发表页面，用户可编辑并自行点击发表。没有自动发表、重发、重试发布或点击发表按钮的路径。取消、页面退出、账号切换、权限变化和重复点击会停止旧任务。广告及禁止复制的内容不绕过限制；未知的新业务卡片会提示并记录类型供后续适配。

## 预加载清理

取消、失败的本任务副本立即清理；进程异常留下且尚未交给发表页的准备文件，超过三分钟在下次清理时移除。已交给原生发表页的副本保留最多 24 小时，供未发表草稿继续读取；过期后草稿可能需要重新准备素材。启动、新任务及运行期间每 30 分钟清扫到期目录，进程不运行时在下次启动补做。

模块转发缓存总上限 512 MiB，单文件 256 MiB，最多 20 张图片；卡片封面下载上限 10 MiB，准备任务最长 180 秒。达到配额时提示失败，避免继续堆积。清理范围仅限模块任务目录，不删除微信自己的图片、朋友圈原缓存或其他用户文件。原生下载服务生成的正常微信缓存仍由微信管理。

## 自动原图修复

原生查看器把主图片记录 ID 与 compressType=1 交给下载服务，服务内部再选择高清子记录。旧实现误把高清子记录 ID 作为主 ID 传入，造成提交后仍无法核验完成。本版按原生查看器的方式传参，完成后仍核对原图记录和实际文件，普通清晰图不能冒充原图。成功并确认原图文件完整后，刷新当前同一条图片的原生查看器状态，避免按钮滞后；不伪造下载回调。

聊天菜单的自动下载原图默认关闭，独立于防撤回，免费／高级／VIP 均可用；开启后对新收到或用户手动打开、且有可用原图的图片，按当前账号名单处理。不强行隐藏原图下载按钮，不伪造完成状态。不批量回扫聊天记录；明确打开的旧图片获得一次有时限的原图检查。视频／文件三分钟防撤回预存及此前平板高级／VIP 权限保持原规则。

## 统一名单规则与菜单提示

红包、转账、原图下载的名单分别保存，微信账号之间互相隔离。个人、群聊分别配置，按最近聊天排序，可搜索；两类名单互斥。

- 总开关关闭：不自动处理，分类和名单配置仍保存。
- 分类关闭：不处理该类任何人。
- 分类开启，白名单为空：处理全部；白名单有选项时，只处理选中的。
- 分类开启，黑名单启用：不处理选中的；空黑名单处理全部。
- 分类开启，两种名单都关闭：处理全部。

上述规则显示在三个功能的名单菜单顶部；关闭分类与空白名单有即时状态说明，避免误以为设置没有效果。

## 验证、构建与回退

静态接口基线为微信 8.0.80（3220），SHA-256：9d9b6c516e8e07e437c81485fde21fe13ce4f61b37d19e793fff40c71be39c0e。验证包括合成行为测试、本地原微信 APK 接口与最终 DEX 检查，手机验证范围以 validation.json 为准，不把它等同于全机型验收。实机覆盖六图及九宫格、普通短视频（含起初没有视频缓存的样例）、视频号卡片、原图下载。用户授权的一条六图朋友圈以仅自己可见发表并已删除，其他草稿已退出；未为验收主动收取真实资金。

Python 3、JDK 17；维护者脚本顺序为 build/build_kernels.py、build/build_loader.py、build/repack_apk.py。独立构建需调整本机工具路径、历史输入、基线 APK 并使用自有签名材料。依赖 android.jar、xposed-api-82.jar、d8.jar、jadx-all.jar，许可证见 licenses/。不包含私钥、密码、激活数据、测试机数据库、聊天日志或截图。

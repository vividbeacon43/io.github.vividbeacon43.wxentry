# WXEntry 2.05 / 动态内核 v246

本源码对应免费、高级、VIP 三通道的 v246 和模块 APK 2.05。新增功能为朋友圈菜单、一键转发独立开关、朋友圈去广告。升级后重启微信。

## 朋友圈菜单与权限

高级版、VIP 的模块主菜单新增“朋友圈”，包含右侧独立滑动开关：开启蓝色、关闭灰色。

- 朋友圈一键转发：新账号及升级用户默认开启，保留原有行为。关闭后不显示长按转发入口，并取消尚未交给发表页的准备任务。开启后长按目标朋友圈进入原生发表页，用户手动发表。
- 朋友圈去广告：默认关闭。开启后按微信原生广告标记过滤朋友圈时间线中的广告，刷新或重新进入朋友圈生效。关闭并刷新后恢复原生列表。

两个开关按微信账号分别保存，互不覆盖，切换账号读取自己的配置。权限检查继续使用加载器验证的当前高级版／VIP 授权；免费、授权失效、模块停用时不启用这两项。设置损坏时关闭两项功能，不用不完整文件重新开启功能。

去广告适配微信 8.0.80（3220）的新版朋友圈列表，在普通内容与广告合并后过滤展示列表。保留原列表和微信数据库，保持普通内容顺序与对象身份；标记读取失败保留原页面。好友自己发布的推广内容作为普通朋友圈保留。功能作用范围为朋友圈时间线。

## 原有转发与媒体规则

沿用 v244 的普通图文、新版类型54图文、九宫格、短视频、视频号卡片及链接转发。普通短视频使用微信完整视频下载服务和完成路径解析，准备可播放文件与封面；仅打开原生发表页。准备失败、取消或账号／权限变化时清理本任务副本，已交给发表页的副本最多保留24小时，未交接的崩溃残留三分钟到期，模块转发缓存总上限512 MiB。

免费红包前台自动拉起拆包、普通皮肤红包兼容、转账缺失字段校验、独立原图下载及个人／群聊名单规则沿用 v244。验证范围与实机结果见 validation.json 和 TESTING.md。

## 验证与构建

微信接口基线：8.0.80（3220），SHA-256：9d9b6c516e8e07e437c81485fde21fe13ce4f61b37d19e793fff40c71be39c0e。

验证包括开关独立性、账号隔离、权限变化、损坏配置、广告／普通行混排、原列表保护和原生合并页接口检查，以及既有功能回归、最终DEX和签名升级／回退检查。手机验证以 validation.json 为准，静态或模拟测试不等同于全部机型验收。

构建脚本顺序：build/build_kernels.py、build/build_loader.py、build/repack_apk.py。需要 Python3、JDK17、android.jar、xposed-api-82.jar、d8.jar、jadx-all.jar，及维护者自有签名材料和基线APK。维护脚本中的本机工具路径与历史输入需要自行调整。许可证见 licenses/。源码不包含私钥、密码、激活记录、手机数据库、聊天日志或截图。

安装包更新清单签名绑定 `v|name|sha256` 三个字段，与加载器更新检查一致。正式及回退安装包共8项清单签名、文件校验及负例测试通过。可用 `build/verify_apk_manifests.py --java-bin <JDK/bin> --manifest-dir <发布包目录> --manifest-dir <回退安装包目录>` 复核。

## 备份与回退

发布前精确备份 APK2.03 / v244。前向回退使用 APK2.06（2.03加载器逻辑）及清单v247（v244内容），允许覆盖安装已经升级的设备。回退后旧版本没有朋友圈菜单和这两个设置开关；授权、账号和聊天数据保持原状态。v247 / APK2.06 已预留，下次正式发布从 v248 / APK2.07 起。

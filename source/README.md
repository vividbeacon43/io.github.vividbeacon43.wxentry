# WXEntry 2.13 / 动态内核 v254

基于线上2.11/v252，修正朋友圈伪集赞样式，增加全选与指定人数随机选择，取消100人固定上限。高级版和VIP权限、账号隔离及默认关闭保持不变。仅在本机展示，不提交真实点赞、评论或好友通知。

## 点赞显示

直接创建微信原生的朋友圈互动布局和点赞控件，复用原生背景、字号、字体、留白、心形图标、分隔线及深浅色资源。移除头像卡片，改为原生爱心与逗号分隔的好友姓名；点击姓名进入该好友资料页。伪评论的头像和编辑功能保留。

已有真实点赞时，读取原生显示文本并保留真实姓名、原有资料链接，追加未重复的本地好友，统一显示为一行可换行的原生点赞文本。仅在本地组合视图挂载期间隐藏原点赞视图；每次原生重绑、清理或关闭时恢复，真实点赞协议对象、数据库和服务器状态均不修改。原生评论保持原视图，图片和表情等不复制、不覆盖。

## 全选和随机选择

模块菜单 → 朋友圈开启伪集赞，长按目标朋友圈文案 → 伪集赞。

- “全选”选择全部可选好友，排除公众号、群聊与微信系统服务联系人。搜索仅筛选可见列表，不改变全选和随机选择的全好友范围。
- “随机选择”中填写1到可选好友总数之间的整数，确定后从全部好友中抽取指定人数，不重复，并替换原选择；取消不修改原选择。
- “清空选择”取消所有选择；保存后更新当前朋友圈的本地点赞。

深色模式下的保存、取消、清理与随机选择按钮使用适配深色背景的文字颜色，避免操作文字与背景混在一起。

不再限制为100位，支持保存和重载5000人等大名单；最大可选人数随实际好友数变化。为避免一次创建大量视图，点赞文字从前20名开始，点击“展开更多”每次增加100名，可逐步查看全部记录。这是展示分页，不会丢弃已选好友。

私有账号文件上限8MiB，最多保留200条朋友圈本地记录；超过总容量时优先淘汰旧记录，保留当前操作目标。不删除微信官方缓存。旧记录中的系统服务账号只从本地点赞显示中排除，不因过滤而损坏原记录。既有v252的格式1记录直接兼容，名单、评论预设、开关和其他功能不迁移、不重置。

## 验证与构建

自动检查包括5000人全选、指定数量随机选择、不重复、边界输入、原列表不变、5000人持久化、账号与权限隔离、数据损坏和空间清理，以及当前微信8.0.80（3220）的原生视图构造、心形绘制、间距与字段契约。手机实际测试范围及是否已发布以validation.json为准；接口和桩测试不等同于界面实测。

构建需Python3、JDK17、Android/Xposed编译库、D8、jadx-all.jar、微信基线APK及自有签名材料。顺序为build/build_kernels.py、build/build_loader.py、build/repack_apk.py；按本机调整工具、历史APK及回退输入路径。源码不含私钥、密码、真实激活、用户日志、数据库或截图。

回退准备为APK2.14（2.11加载器逻辑）和清单v255（精确v252内核内容）。v252对超过100人或超过2MiB的本地文件会关闭本地展示而保留文件，必要时通过清空本地记录恢复；真实社交数据不受影响。v255/APK2.14预留，下个正常发布从v256/APK2.15起。

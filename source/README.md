# WXEntry APK 2.17 / 动态内核 v260

在微信主页长按左下角「微信」页签，进入微信原生未读聊天窗口；右下角新增「一键已读」。免费版、高级版、VIP 均可使用。

- 复用左侧原生「返回」按钮的布局、圆角底色、文字大小与图标框大小，在右侧镜像对齐。图标使用微信自带的已读勾选图标，支持浅色 / 深色模式。
- 点击执行现有的一键已读逻辑，执行期间防止重复点击。保留左侧返回按钮和微信原生未读列表行为。
- 原模块「聊天 → 一键已读」入口保留。未读数归零后重新打开窗口显示「暂无未读聊天」。
- 本次只更新三版动态内核；APK 仍为 2.17（117），无需重装 APK。模块内更新到 v260 并重启微信后生效。

## 验证范围

在已连接的 OnePlus 9 Pro / Android 14 / 微信 8.0.80（3220）上，使用最终签名 VIP 内核实测：原生页面有 2 个未读聊天，点击后未读数归零，原生返回正常，重进空列表正常，深浅色按钮样式正常，无重复按钮。系统浅色主题已恢复，原 VIP 激活、六项原设置和充电亮屏 7 保持不变。免费 / 高级版通过构建及 DEX 检查，未分别切换实际账号授权做真机测试。

此前 v258 的 VIP 定时图文朋友圈、息屏 CPU 唤醒与错过时间手动确认规则保留。原有红包、转账、原图下载、防撤回和朋友圈功能源码未修改；本次没有重复执行真实收款或定时发布测试。用户已取消的 Galaxy S25 防撤回问题未作改动。

## 源码与构建

kernel 为三版内核与功能源码，loader 为现有 2.17 加载器，tests 为行为与原生 DEX 接口检查，build 为构建脚本，server 为本次未改动的服务端源码，baseline-v212 / licenses 为回归基线和依赖许可证。

构建需要 JDK 17、android.jar、Xposed API 82、D8、dexlib2 / jadx-all.jar。build/build_kernels.py 支持 --java-bin、--libs、--python-libs、--native-apk。提供 --signing-key 时生成使用自己签名的内核；工具链、微信 APK、签名私钥、证书库密码和真实用户数据不随源码分发。

# WXEntry 1.99 / 内核 v240：视频文件防撤回与原图自动下载

状态：APK 1.99 和免费/高级/VIP 三通道 v240 已发布。本次新增的视频／文件预存、独立自动下载原图及其黑白名单，三个版本均可用。平板实验功能仍仅限高级版/VIP。

## 视频与文件防撤回

此前数据库更新被拦截后，微信的原生 RevokeMsgEvent 仍可能取消视频下载、清理媒体数据。本版对收到的视频（43）、短视频（62）和普通附件（49/子类型 6）在原生撤回消费者修改消息及发布清理事件之前拦截，保留原消息并使用现有同行撤回备注。不新增聊天消息行，不分配消息 ID。自己撤回、其他消息类型和关闭防撤回时使用原有路径。

防撤回开启时，通过微信原生视频与附件下载服务预存完整文件副本。没有完成下载、原生大小不匹配或文件仍在修改时不发布副本。三分钟期限按收到该消息的时间计算，重复写入或进程重启不续期。

收到后满 180 秒仍未撤回，清理模块私有的预存副本和临时元数据，不删除微信自己的原文件。期限内已撤回的副本转为保留状态，不因三分钟到期而删除。启动时清理过期副本并恢复尚在期限内的任务；微信进程停止期间不能执行清理，下一次启动补做。恢复前重新核验账号、会话、消息 ID、服务器 ID及原生路径，并验证副本哈希；不覆盖已经存在的官方文件。

预存单文件上限 256 MiB，模块副本总额上限 512 MiB；达到上限时跳过副本，撤回前置拦截仍生效。微信未提供、已失效或下载未完成的文件不能凭空恢复。网络、服务器及微信下载限制仍由原生服务决定。

## 独立自动下载原图

聊天 → 自动下载原图，默认关闭，使用现有右侧蓝／灰小滑块。原发送图片的选项明确为“发送原图”。

开启后，对收到且微信标示有可用原图的图片，通过微信原生原图记录和 compressType=1 队列下载；普通清晰图完成不等同于原图完成。不启动图片查看页、不伪造完成回调，不发送消息。原图保存在微信自己的图片路径中，用户正常查看和管理。

该开关独立于防撤回，即使关闭防撤回仍可自动下载原图。模块整体关闭、该开关关闭、账号切换或名单不允许时，不再提交下载；只移除本模块的监听，不全局取消微信或查看器的下载任务。原有图片防撤回的版本权限保持不变。

## 原图下载黑白名单

聊天 → 原图下载黑白名单（个人 / 群聊）。按账号独立保存，和红包、转账名单分开。个人、群聊分别设置；白名单和黑名单互斥。分类关闭时不自动下载，两名单均关闭时不限名单；启用空白名单时不处理任何人。列表按最近聊天时间倒序，支持搜索并保留隐藏的已选项。

收到图片、任务排队后和实际提交前均检查当前账号与名单。排队期间关闭开关或修改名单不会让之前的待提交任务绕过新规则。

## 安装与构建

建议覆盖安装 APK 1.99，检查动态内核更新至 v240 并重启微信。高级版/VIP 平板功能仍需要有效已签名授权；免费版可以使用本次新增媒体和原图功能。

源码包含实际发布的内核、加载器、测试和维护者构建脚本。Python 3 / JDK 17；依次运行 build/build_kernels.py、build/build_loader.py、build/repack_apk.py。独立构建需配置本机工具路径、原 APK 基线、签名材料和历史构建输入。依赖 android.jar、xposed-api-82.jar、d8.jar、jadx-all.jar；许可见 licenses/。

不包含签名私钥、密码、真实激活、缓存授权、用户日志、聊天文件或手机截图。授权后台不修改，服务不重启。

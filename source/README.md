# WXEntry 2.15 / 动态内核 v256

基于2.13/v254，为VIP增加红包祝福语和自动接收转账备注的关键词过滤。两种功能、不同微信账号分别保存规则，与原有黑白名单、分类和延时设置独立。免费版、高级版不提供关键词菜单，也不运行保存的VIP关键词规则；原有领取权限不变。

## 使用

模块菜单 → 红包 → 红包关键词过滤（VIP）／转账关键词过滤（VIP）。

- 命中关键词就跳过：任意一个词命中，停止自动处理。
- 仅领取命中关键词的：只处理至少命中一个词的红包／转账。
- 两个右侧小滑块互斥，开启一个会关闭另一个；两项都关闭即不限制关键词。默认均关闭。
- 模糊匹配为文字包含关键词；精确匹配为整段祝福语／备注等于关键词。忽略首尾空格，区分英文大小写，按普通文字匹配，不执行正则表达式。
- 每行一个词，支持1个或多个，空行忽略、重复词合并；最多100个词、每词200字。保存后生效，取消不修改；开启过滤时不能保存空词表。

红包只读取原卡片wcpayinfo.sendertitle祝福语，转账只读取wcpayinfo.pay_memo备注。不匹配发件人、会话名、金额、XML字段名或其他聊天内容。转账没有备注时按空文字判断；开启过滤后无法可靠读取文本时暂停自动操作，保留微信手动领取能力。

仍须同时符合原有规则：关闭的个人／群聊分类不处理，非空白名单只处理所选对象，空白名单处理全部，黑名单排除所选对象。关键词不能绕过这些规则或授权检查。延时结束、红包实际拆包、转账实际确认前都会重新检查当前规则；修改设置不会追领之前被跳过的历史消息。

## 兼容与数据

打赏菜单改为打开https://www.zidianidc.com/shop/Z2EWXNI6；找不到可用浏览器或浏览器无法启动时自动复制同一链接并提示。剪贴板不可用时展示可长按复制的链接。

沿用每账号、每功能的format=1文件，新增keyword.rule、keyword.match、keyword.words字段；旧文件自动按关键词关闭处理，原有开关、黑白名单和秒数不重置。关键词使用UTF-8转义存储，损坏或不完整配置停止自动处理。降级到非VIP保留词表但不执行VIP关键词过滤。

原生前台领取继续使用微信完整红包模型和页面选择器，保留红包皮肤。已有任务使用已验证的原消息会话，避免页面缺少会话参数时误停拆包。静默领取保持后台路径；日志不记录实际关键词、祝福语或转账备注。

回退准备为APK2.16（精确2.13加载器逻辑）／清单v257（精确v254内核内容）。回退后没有关键词过滤，原有名单和领取开关保留；后续正常版本从2.17/v258起。源码不含私钥、密码、真实授权、日志、数据库或手机截图。
